# 2-4 Week Hackathon Delivery Plan

## Week 1: Foundations + MVP flow

- Finalize architecture, data contracts, and UX wireframes.
- Integrate FastAPI endpoints and Flutter shell screens.
- Implement map dashboard with color-coded roads.
- Add image upload/capture and demo detection pipeline.

## Week 2: Core intelligence features

- Add road health scoring and map score updates.
- Build chatbot with road + budget + complaint context.
- Implement structured complaint generation and tracking timeline.
- Add transparency module (budget vs condition mismatch).

## Week 3: Robustness + offline mode

- Implement local offline queue for complaints and detections.
- Add sync flows and edge-case handling (network drops, retries).
- Add risk prediction engine and intelligence panel.
- Add deterministic demo mode with scripted scenarios.

## Week 4: Polish + judging narrative

- Performance tuning for low-end devices.
- Improve visual storytelling and transitions.
- Add telemetry/logging and stability checks.
- Practice timed demo walkthrough and Q&A drill.

## Delivery checklist

- AI detection is reproducible in live demo.
- Transparency mismatch stories are visible and defensible.
- Chatbot answers governance queries in <3 turns.
- Offline mode works without internet.
- End-to-end complaint flow is demonstrated from image to ticket.
