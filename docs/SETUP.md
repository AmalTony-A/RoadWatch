# Setup Instructions

## Prerequisites

- Python 3.11+ (3.12 recommended)
- Flutter 3.22+ and Dart SDK
- Android Studio/Xcode (for mobile)
- Optional: MongoDB, OpenAI API key, YOLO weights

## 1) Backend setup

From `backend/`:

```bash
python -m venv .venv
# PowerShell: .\.venv\Scripts\Activate.ps1
# cmd.exe: .venv\Scripts\activate.bat
# bash/zsh: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Health check:

```bash
curl http://localhost:8000/health
```

Optional smoke test (with backend running):

```bash
python scripts/smoke_test.py
```

Unit/API tests:

```bash
pytest -q
```

## Docker option (backend + MongoDB)

From repo root:

```bash
docker compose up --build
```

This starts:

- backend at `http://localhost:8000`
- MongoDB at `mongodb://localhost:27017`

## 2) Frontend setup

This repo includes Flutter app source (`lib/`, `pubspec.yaml`).
If platform folders are missing, generate once:

```bash
cd frontend
flutter create .
```

Then install deps and run:

```bash
flutter pub get
flutter run
```

If you need a different backend URL, pass it at build time:

```bash
flutter run --dart-define=API_URL=http://localhost:8000
```

For online deployment, build the web app with your deployed backend URL:

```bash
flutter build web --release --dart-define=API_URL=https://your-backend-domain.example
```

## 3) Configure API URL

Update backend URL in `frontend/lib/config/app_config.dart`:

- Android emulator: `http://10.0.2.2:8000`
- iOS simulator: `http://127.0.0.1:8000`
- Web/local desktop: `http://localhost:8000`

If you run Flutter Web on a custom port, either keep the backend CORS origin as `*` or make the port match your `FRONTEND_ORIGIN` value.

Important: if `API_URL` is not provided during an online build, the web app will fall back to the current browser origin. That works when your frontend and backend share the same domain or are proxied together, but you should set `API_URL` explicitly when they are hosted on different domains.

## 4) Google Maps setup

1. Create Google Cloud project.
2. Enable Maps SDK (Android/iOS/Web).
3. Add API key to platform configs generated by Flutter:
   - Android: `android/app/src/main/AndroidManifest.xml`
   - iOS: `ios/Runner/AppDelegate.swift`
   - Web: `web/index.html`

## 5) Optional AI integrations

- Add YOLO weights path in backend `.env`: `YOLO_MODEL_PATH=...`
- Add OpenAI key in `.env`: `OPENAI_API_KEY=...`

Without these, app runs in stable demo mode with fallback behavior.
