# Frontend (Flutter)

## Run

```bash
flutter create .
flutter pub get
flutter run
```

If backend runs on localhost, update `lib/config/app_config.dart` for your device.

## Key modules

- Home dashboard with map + road colors
- AI capture/upload + bounding box rendering
- Civic assistant chatbot interface
- Transparency panel (budget vs actual condition)
- Complaint timeline and offline queue sync
- Intelligence panel with trends + risk prediction

## Demo assets

Preloaded demo images are in `assets/demo/` and can be run directly from the Capture screen.
